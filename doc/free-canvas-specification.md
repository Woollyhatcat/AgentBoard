# 自由黑板规格 v0.3

2026-11-11。本文记录已确认的桌面端开发范围；与 v0.1／v0.2 的布局、文本排版及版本规则冲突时以本文为准。六类卡片、资源授权、锁定、软删除、幂等回执和固定时点读取继续适用。

2026-11-12补充：新增第七类interactive交互演示，接口、参数持久化和运行范围以 [交互卡片文档](interactive-cards.md) 为准；原有布局和版本规则继续适用。

## 空间、卡片和相机

- 共享布局采用 `layout={space:"world",x,y,w,h,z,height_mode}`。100% 相机比例下一个画布单位等于一个 CSS 像素；坐标可以为负、卡片允许重叠。`height_mode` 为 `auto|fixed|expanded`；文本默认 auto，其他类型默认 fixed。坐标边界 ±10,000,000，尺寸 180～10,000 × 100～20,000，层级为安全整数。
- 创建时可省略 layout 自动放置，或提供 world 布局；可传 `anchor_card_id` 将新卡片放在关联卡片附近。自动放置尽量不重叠，不移动已有卡片。用户创建以当前可见空间为起点。
- 拖动标题栏移动卡片，边角调整尺寸；正文支持选择和操作控件。WASD、方向键、空白拖动、空格拖动和中键均可平移视角。鼠标滚轮或触控板捏合围绕指针缩放，范围 10%～400%。可滚动的卡片正文优先响应普通滚轮，Ctrl＋滚轮可缩放画布。输入文字及操作控件时，按键交由对应控件处理。
- 相机有缩放按钮、100%、适配全部、原点和选中卡片定位。本机保存视角；浏览窗口尺寸不改共享坐标。外部更新只通知，不主动移动用户视角。
- 选中卡片临时突出；显式置顶／置底才保存 z。恢复优先原位置，重叠时安排附近空位并提示。本轮不另做手机端布局。

## 文本与字号

- Markdown 正文支持标题层级、有序／无序／嵌套列表、表格、引用、代码块、任务列表、链接和安全资源图片。HTML 按文字展示，链接与图片不执行脚本。
- 支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 行内和块公式；代码内容不解析公式。公式错误在原位置可辨认，保留源码。
- 文本卡片 `props.font_size` 为共享正文基准字号，整数 12～48，默认 16；网页与 MCP 创建／编辑均可设置。Markdown 标题和公式相对基准字号排版。标题和描述为纯文字。字体族／行距调节不属于本次范围。
- 阅读态渲染正文；编辑态提供源码和实时预览。草稿不写入共享状态。
- auto 按内容计算高度，阅读上限 720 单位，超出后内部滚动；expanded 完整展开，fixed 按共享高度滚动。改变内容／字号只改变自身高度，不推挤其他卡片，不自动缩小字号。
- 高度为正文、字号、宽度与模式的渲染结果；自动高度不是用户布局写入，不制造额外版本冲突。`layout.h` 为固定模式的高度和无渲染客户端的放置估计。

## 版本和 MCP

- 看板 `schema_version="2.0"`，卡片 `layout.space="world"`。`version` 仍为整卡有效提交序号；新增 `content_version`、`layout_version`。
- `edit_card` 可以传 `expected_content_version`、`expected_layout_version`：修改内容字段时核对内容版本，修改布局时核对布局版本，两种修改一起提交时分别核对。传 `expected_version` 时仍使用保守整卡检查。生命周期及锁定仍需整卡版本。
- 内容修改不改变布局版本，布局修改不改变内容版本；锁定／解锁、删除／恢复同时改变两者，防止旧操作跨越保护边界。
- 创建或编辑布局必须明确 `space:"world"`，旧网格写入拒绝，不能把 w=4 解释成 4 像素。类型查询公布默认布局、字号和版本用法。所有写入继续使用 command_id／幂等语义。
- 当前工具名称保持不变；普通 Agent 可维护布局、层级和字号，仍不能解锁或扩大文件授权。

## 迁移与个人设置

- 首次升级在 SQLite 独占写事务内，使用数据库 backup API 建立完整备份，再一次迁移活动卡片、回收站、历史事件及回执内嵌的卡片和冻结分页数据。保留标识、内容、资源和原版本。
- 旧网格按固定参考单元转换：横向 112、纵向 88、间距 16。文本补 font_size=16、auto。记录旧 revision 为新的增量基线；过旧消费者须重新取快照。
- 明暗主题、主题色、画布背景、网格显示、紧凑程度、吸附和相机按本机保存；不作为共享卡片修改。字号随卡片共享。
- 升级后旧进程若仍加载 v1 代码，明确拒绝操作，提示重新连接，避免旧进程误写新布局。

## 验收

1. MCP 创建 24 字号 Markdown／公式文本卡片；网页能正确排版，源码和预览一致。
2. 自由移动、负坐标、重叠、缩放、定位、层级与重载持久化正常；操作控件不拖动卡片。
3. 用户移动与 Agent 改正文互不覆盖；同一内容／同一布局的旧版本修改仍拒绝。
4. 自动高度、固定高度和展开模式可切换，字号变化不移动其他卡片。
5. 本机主题和视角重载后恢复；外部更新不抢视角。
6. 旧数据迁移后标识／资源／回收站／回执保留，有可恢复备份；旧网格写入明确报错。
